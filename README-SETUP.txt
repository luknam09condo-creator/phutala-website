PHUTALA CMS — SETUP (EN/TH)

1. Create a private GitHub repository named phutala-website.
2. Upload ALL contents of this folder into the repository root, including .pages.yml (hidden file), index.html, content/ and media/.
3. Open https://app.netlify.com/start -> Import existing project -> GitHub -> select the repo.
4. For this plain HTML website, build command is blank; publish directory is the repository root (.).
5. Open https://app.pagescms.org/ -> Sign in with GitHub -> install Pages CMS GitHub app on the repository -> select PHUTALA content.
6. Edit texts and photos, click Save. Each change commits to GitHub and automatically redeploys through Netlify.
7. This editor is at app.pagescms.org, NOT at https://your-site/admin. Do not expose edit access to customers.

IMPORTANT: Earlier Netlify Drop sites do not automatically connect to GitHub. Create or link a Git-connected deployment to use auto-updates.

Data caveat: Only 1-bedroom private pool and starting price THB 2790 have been confirmed. Other types' pool details and prices are not asserted.
